# FRED Economic Analysis Notebooks

This repository contains exploratory economic and policy-oriented analyses using data from the Federal Reserve Economic Data (FRED) database.

Current topics include:

* Inflation dynamics
* U.S. unemployment cycles
* Nuclear energy production trends
* Utilities employment and energy infrastructure analysis

These notebooks are designed as short-form analytical exercises that combine economic data visualization, exploratory quantitative analysis, and policy interpretation.

The project also serves as a technical training portfolio focused on strengthening skills in:

* data cleaning,
* time-series analysis,
* visualization,
* reproducible workflows,
* and applied policy analysis using Python.
